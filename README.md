# Bovino em Foco — Área de Membros

Página estática da área de membros com acesso à oferta principal e aos três produtos complementares (order bumps).

## Estrutura

- **Oferta principal:** 100 Técnicas Bovinas
- **Order bump 01:** Caderno Sanitário Inteligente do Rebanho
- **Order bump 02:** Kit de Biossegurança e Prevenção na Fazenda
- **Order bump 03:** Manual Ilustrado do Parto ao Desmame

Os entregáveis ficam exclusivamente no Google Drive. O GitHub e o Vercel hospedam somente a interface leve (`index.html` e identidade visual), sem cópias dos PDFs, planilhas, apresentações ou pacotes ZIP.

## Publicação

O projeto Vercel é `area-de-membros-bovino` e está conectado ao repositório GitHub `oHenriqueCorreia/area-de-membros-bovino`.

> A pasta `CRIATIVOS BOVINOS EXEMPLOS` não faz parte dos entregáveis e não foi processada.
